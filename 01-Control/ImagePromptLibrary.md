# ImagePromptLibrary.md
# CLASS 5 ENGLISH GRAMMAR — STANDARD IMAGE PROMPTS

## 0. INTRODUCTION

This document provides a library of standardized, reusable prompts for generating educational illustrations. The goal is to ensure visual consistency, pedagogical alignment, and production efficiency. Each prompt is designed to be adapted for specific chapter content.

---

## 1. CORE PRINCIPLES

-   **Pedagogical Purpose:** Every image must have a clear educational objective.
-   **Visual Consistency:** All illustrations should share a common style, defined in the prompts.
-   **Character Integrity:** Recurring characters must be depicted consistently, as defined in `CharacterBible.md`.
-   **Clarity and Simplicity:** Visuals should be uncluttered and easy for a 10-year-old to interpret.
-   **Originality:** All generated assets must be original and free of copyrighted material.

---

## 2. STANDARD PROMPT STRUCTURE

Each prompt in this library follows a template:

-   **Prompt ID:** A unique identifier (e.g., `CHAR-DIALOGUE-01`).
-   **Purpose:** The pedagogical reason for this type of image.
-   **Base Prompt:** The core text for the image generation model. This includes style, characters, and setting.
-   **Customization Notes:** Instructions on how to adapt the prompt for a specific instance (e.g., by adding details about the action, expression, or concept).

---

## 3. PROMPT LIBRARY

### PROMPT ID: `CHAR-DIALOGUE-01`

**Purpose:** To illustrate a conversation between two or more characters, setting a context for a new grammar concept.

**Base Prompt:**
```
Create an original educational illustration for a Class 5 English grammar textbook. The image should show the characters [Character A] and [Character B] having a conversation in a [Setting, e.g., classroom, park, library]. [Character A] looks [Expression, e.g., curious, confused] and [Character B] looks [Expression, e.g., thoughtful, excited]. The composition should clearly show the interaction between them.

Use a clean, professional, age-appropriate children's textbook illustration style with friendly characters. Use the character designs from the project's Character Bible (e.g., Maya with glasses, Rohan with an energetic expression).

NEGATIVE INSTRUCTIONS: No watermarks, no logos, no copyrighted characters, no text, no distorted objects, no inappropriate imagery, no excessive decoration.
```
**Customization Notes:** Replace bracketed placeholders `[ ]` with specific details from the chapter's context.

### PROMPT ID: `CONCEPT-VISUAL-01`

**Purpose:** To create a visual metaphor or a clear example of a core grammar concept.

**Base Prompt:**
```
Create an original educational illustration for a Class 5 English grammar textbook. The image must visually explain the concept of [Grammar Concept, e.g., 'a collective noun']. Show [Specific Scene, e.g., 'a flock of birds flying together' or 'a bunch of keys on a table']. The visual elements should be distinct and clearly represent the concept.

Use a clean, professional, age-appropriate children's textbook illustration style. The style should be simple and focused on the educational objective.

NEGATIVE INSTRUCTIONS: No watermarks, no logos, no copyrighted characters, no text, no distorted objects, no inappropriate imagery, no excessive decoration.
```
**Customization Notes:** Clearly define the `[Grammar Concept]` and the `[Specific Scene]` that will best illustrate it.

### PROMPT ID: `SCENE-SEARCH-01`

**Purpose:** To provide a busy scene where learners can identify multiple examples of a grammar point (e.g., nouns, prepositions, adjectives).

**Base Prompt:**
```
Create an original educational illustration for a Class 5 English grammar textbook. The image should be a detailed scene of a [Setting, e.g., busy park, a classroom during an activity, a market]. The scene must contain multiple clear examples of [Target Items, e.g., different types of nouns, objects in various positions].

Use a clean, professional, age-appropriate children's textbook illustration style with a lot of detail to encourage exploration.

NEGATIVE INSTRUCTIONS: No watermarks, no logos, no copyrighted characters, no text, no distorted objects, no inappropriate imagery.
```
**Customization Notes:** Specify the `[Setting]` and list the `[Target Items]` that must be included and identifiable.

---

### PROMPT ID: `DETECTIVE-ERROR-01`

**Purpose:** To illustrate a scenario for a "Grammar Detective" activity, often featuring a humorous or obvious mistake.

**Base Prompt:**
```
Create an original educational illustration for a Class 5 English grammar textbook. The image should show a funny or slightly incorrect situation. For example, show the character Leo the parrot [Action, e.g., pointing to a sign with a misspelled word] or the character Rohan [Action, e.g., looking confused while holding two different shoes]. The error should be visual and amusing.

Use a clean, professional, age-appropriate children's textbook illustration style, consistent with the character designs from the project's Character Bible.

NEGATIVE INSTRUCTIONS: No watermarks, no logos, no copyrighted characters, no text (unless the text itself is the error and is specified), no distorted objects, no inappropriate imagery.
```
**Customization Notes:** Describe the specific visual `[Action]` or error that needs to be depicted.

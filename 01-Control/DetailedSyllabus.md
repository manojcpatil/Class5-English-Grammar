# 1. CURRICULUM DESIGN

The course integrates:

GRAMMAR
+ VOCABULARY
+ READING AWARENESS
+ SPEAKING/LISTENING
+ WRITING
+ EDITING
+ REASONING

Progression:

sentence awareness
→ naming and describing
→ action and relationships
→ sentence accuracy
→ vocabulary
→ transformation
→ communication
→ writing
→ integrated review.

# 2. UNIT MAP

## UNIT 1 — SENTENCES AND MEANING

### Chapter 1 — Complete Sentences

Coverage:
- words and word order;
- meaningful groups;
- complete thought;
- sentence boundary;
- capitalisation;
- basic punctuation;
- subject/predicate introduction.

Outcomes:
Learners can recognise, construct and punctuate simple complete sentences.

Spiral links:
None initially; becomes prerequisite for later chapters.

---

### Chapter 2 — Kinds of Sentences

Coverage:
- statement;
- question;
- command/request/instruction;
- exclamation;
- wish where appropriate;
- punctuation.

Outcomes:
Learners can identify purpose and construct appropriate sentence types.

---

### Chapter 3 — Nouns

# 3. CROSS-CURRICULAR SKILL PROGRESSION

## Grammar
Recognition → explanation → accurate use → editing → production.

## Vocabulary
Meaning → context → relation → precision → production.

## Writing
Sentence → connected sentences → paragraph → functional text → composition.

## Speaking
Controlled response → pair interaction → role play → short presentation.

## Reading
Notice grammar → infer meaning → analyse language choices.

## Metacognition
Answer → explain → check → revise.

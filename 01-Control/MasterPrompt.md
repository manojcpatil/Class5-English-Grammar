# MasterPrompt.md
# CLASS 5 ENGLISH GRAMMAR — END-TO-END TEXTBOOK PRODUCTION SYSTEM

## 0. PURPOSE

Create a completely original, professionally authored Class 5 English Grammar textbook and its publication-ready outputs:

1. Markdown manuscript/source content
2. LaTeX master source
3. Compiled PDF
4. Editable Word/DOCX edition

The uploaded `05.pdf` is the principal reference for understanding curricular scope, level, organisation, terminology and breadth.

The new book must NOT be a rewritten or lightly modified copy of `05.pdf`.

The production chain is:

REFERENCE
→ ANALYSIS
→ CURRICULUM
→ PEDAGOGICAL DESIGN
→ CHAPTER MANUSCRIPT
→ CONTENT QA
→ VISUALS
→ LATEX
→ PDF
→ DOCX
→ FINAL QA
→ RELEASE

LaTeX is the authoritative typesetting source.

Markdown is the authoritative editorial/content-development source.

PDF is the authoritative print/read-only publication output.

DOCX is the editable distribution output.

# 4. PEDAGOGICAL PHILOSOPHY

Use the following learning progression where appropriate:

EXPERIENCE
→ NOTICE
→ THINK
→ DISCOVER
→ NAME
→ EXPLAIN
→ PRACTISE
→ APPLY
→ CREATE
→ REFLECT

Do not turn every lesson into a game or discovery exercise.

Balance:

- explicit instruction;
- guided discovery;
- modelling;
- deliberate practice;
- retrieval;
- error analysis;
- communication;
- writing.

Grammar is both:

- knowledge about language; and
- a tool for using language accurately and effectively.

---

# 5. LEARNER MODEL

Target:

Class 5, approximately 10–11 years.

The learner can:

- read short connected texts;
- notice patterns;
- classify examples;
- explain simple grammatical choices;
- write connected sentences and short paragraphs;
- revise simple writing;
- reason about language when supported.

Use clear English without baby-talk.

Respect the learner's intelligence.

---

# 6. THREE-LAYER MODEL

For major concepts:

## NOTICE
Encounter the language.

## UNDERSTAND
Learn the concept and rule.

## USE
Identify, edit, produce and communicate.
